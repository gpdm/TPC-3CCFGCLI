# 3C5X9CFG — Original 3Com Configuration Utilities

This directory contains original copies of the 3Com EtherLink III (3C509/3C5x9)
DOS configuration utilities, organized by version:

- `1.2/3C509.EXE`
- `2.1/3C5X9CFG.EXE`
- `3.0/3C5X9CFG.EXE`
- `3.2/3C5X9CFG.EXE`

These are the original 3Com 3C509 configuration utilities, kept in this
repository for the sake of completeness — e.g. as reference material for
behavior comparison, and as writer/observer counterparts in real-hardware
conformance testing (see `TESTHWC.MK`).

Original copies can be sourced from:

- [3Com EtherLink III drivers](http://www.win3x.org/win3board/viewtopic.php?t=281&view=min) (includes 3C509.EXE v3.x)
- [3Com EtherDisk v3.5 for the EtherLink III Family](https://archive.org/details/3com_etherdiskv35etherlinkiiifamily_830346005) (includes 3C5X9CFG.EXE v2.1)
- [3Com EtherDisk v3.x](https://archive.org/details/3-com-ether-disk-v-3.x) (includes 3C509.EXE v1.2)
